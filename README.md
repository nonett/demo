# 🏆 Демоэкзамен 2026 (Вариант 2): Модуль 1 (Сетевой фундамент)

Это подробная инструкция для безошибочного развертывания **Модуля 1** демоэкзамена 2026 года. Скрипт `iti1.sh` делает всю сетевую работу: настраивает Router-on-a-Stick, виртуальный коммутатор, OSPF, GRE-туннели, DHCP, NTP (Stratum 7) и пробрасывает порты.

От вас требуется только правильно склонировать виртуалки, подключить виртуальные кабели (LAN Segments) и запустить скрипт.

---

## 🛠️ ЭТАП 1: Подготовка виртуальных машин (VMware)

На экзамене выдают два чистых образа: **Ubuntu Server** (без графики) и **Ubuntu Desktop** (с графикой для HQ-CLI). 
Сделайте из них 7 полных клонов (`Manage` ➔ `Clone...` ➔ `Create a full clone`):
* Из **Ubuntu Server** — 6 машин: `ISP`, `HQ-RTR`, `HQ-SW`, `BR-RTR`, `HQ-SRV`, `BR-SRV`.
* Из **Ubuntu Desktop** — 1 машину: `HQ-CLI`.

**ОЗУ (RAM):** Для выполнения Модуля 1 всем машинам достаточно выделить по **1 ГБ** оперативной памяти.

---

## 🔌 ЭТАП 2: Подключение проводов (LAN Segments)

Мы используем `LAN Segments` — изолированные виртуальные провода.
В настройках любой виртуалки перейдите в `Network Adapter` ➔ `LAN Segments...` ➔ `Add` и создайте 6 сегментов:
`ISP-HQ`, `ISP-BR`, `HQ-Net`, `SRV-Net`, `CLI-Net`, `BR-Net`.

Добавьте адаптеры машинам строго по этой таблице (лишние удалите кнопкой `Remove`, недостающие добавьте кнопкой `Add -> Network Adapter`):

| :--- | :--- | :--- | :--- | :--- |
| 🌍 **ISP** | `NAT` | `ISP-HQ` | `ISP-BR` | - |
| 🖧 **HQ-RTR** | `NAT` | `ISP-HQ` | `HQ-Net` | - |

## 🚀 ЭТАП 4: Инструкция по запуску скрипта

### Шаг 1. Скачивание скрипта
Включите все машины. Убедитесь, что интернет работает (через первый адаптер `NAT`). 
Зайдите на каждую ВМ под пользователем `root` (команда `sudo su`).

Выполните загрузку через `git clone`:
```bash
apt update && apt install git -y
git clone [https://github.com/nonett/demo](https://github.com/nonett/demo)
cd demo
chmod +x iti1.sh

```

*(Если на `HQ-CLI` нет интернета или прав, обязательно сделайте `sudo su`, а затем повторите команды).*

### Шаг 2. ИЗОЛЯЦИЯ СЕТЕЙ (Отключение кабеля NAT) 🛑

Не выключая машины, перейдите в их настройки в VMware (`VM -> Settings`).
У **ВСЕХ машин КРОМЕ ISP** выберите первый адаптер (`Network Adapter 1`, который NAT) и **СНИМИТЕ галочку "Connected"** сверху справа. У `ISP` галочку оставляем (ему нужен интернет)!

> 💡 *Когда скрипт попросит ввести имя интерфейса (например, `ens33` или `ens34`), вводите те интерфейсы, у которых статус `UP`. Отключенный `NAT` интерфейс вводить нельзя!*

### Шаг 3. ЗАПУСК СКРИПТА

Запускайте скрипт `./iti1.sh` строго по очереди. Ждите появления зеленой надписи "[УСПЕХ]", прежде чем переходить к следующей машине:

1. **ISP** ➔ Пункт `1`
2. **HQ-RTR** ➔ Пункт `2`
3. **HQ-SW** ➔ Пункт `3`
4. **BR-RTR** ➔ Пункт `4`
5. **HQ-SRV** ➔ Пункт `5` *(Настроит только сеть и SSH, без сервисов)*
6. **BR-SRV** ➔ Пункт `6` *(Настроит только сеть и SSH, без сервисов)*
7. **HQ-CLI** ➔ Пункт `7` *(Скрипт дождется получения IP по DHCP)*

## 🧹 ЭТАП 5: Удаление следов скрипта (Очистка)

**⚠️ ОБЯЗАТЕЛЬНО!!!**
Чтобы эксперт не увидел, что вы пользовались автоматизацией, после успешной настройки удалите скачанные файлы.

Выйдите из папки репозитория и удалите её целиком:

```bash
cd ~
rm -rf demo

```

Для надежности очистите историю команд в терминале:

```bash
history -c

```

## 📋 Чек-лист проверок для эксперта

Вставляйте эти команды в терминал, делайте скриншоты вывода и добавляйте в отчет.

**1. Проверка выдачи адресов (HQ-CLI):**

```bash
ip a

```

*(Должен быть выдан адрес из пула 192.168.20.10 - 192.168.20.30).*

**2. Проверка туннеля и динамической маршрутизации OSPF (HQ-RTR):**

```bash
vtysh -c "show ip ospf neighbor"
vtysh -c "show ip route"

```

*(Должен быть виден сосед `2.2.2.2` со статусом `Full`, а в таблице маршрутов должны быть строки с буквой `O`).*

**3. Проверка безопасного удаленного доступа и DNAT (HQ-CLI):**
*(В терминале обычного пользователя)*

```bash
ssh sshuser@192.168.10.2 -p 2012

```

*(Пароль: `P@ssw0rd`. Должен появиться баннер `Authorized access only`).*

**4. Проверка синхронизации времени NTP (BR-RTR или серверы):**

```bash
chronyc sources

```

*(Слева от IP-адреса локального провайдера должна стоять звездочка `*`, подтверждающая успешную синхронизацию).*
